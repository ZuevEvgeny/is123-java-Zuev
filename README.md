# Smart Home Configurator

Приложение для конфигурирования и визуализации систем умного дома с поддержкой 2D и 3D режимов, симуляцией устройств и голосовым управлением.

## Функциональные возможности

### Редактор планировки
- Создание комнат с произвольной формой
- Рисование стен с возможностью добавления дверей и окон
- Расстановка мебели, ламп и датчиков из встроенной библиотеки
- Редактирование свойств объектов (размер, поворот, масштаб)
- Экспорт плана в SVG формат

### 3D Визуализация
- Полноценный трёхмерный обход сцены (WASD + мышь)
- Динамическое освещение от ламп
- Текстуры стен, полов, дверей и окон
- Анимация вентиляторов и кондиционеров
- Эффекты дыма при срабатывании датчиков

### Симуляция умного дома
- Автоматическое управление освещением по датчикам движения
- Поддержка сценариев: День, Вечер, Ночь, Рассвет
- Расписание автоматизации
- Управление кондиционерами и вентиляторами

### Голосовое управление
- Активация по фразе "Умный дом"
- Поддерживаемые команды: включение/выключение света, регулировка яркости, управление кондиционером и вентилятором
- Применение сцен голосом

### Устройства
- Лампы (обычные и умные)
- Датчики: температуры, влажности, освещённости, движения, дыма
- Кондиционеры (настенные)
- Вентиляторы (потолочные и напольные)

### База данных
- SQLite с автоматическим созданием таблиц при первом запуске
- Сохранение и загрузка проектов
- Хранение стен, комнат, мебели и устройств

## Требования к системе

- Java 17 или выше
- Windows / Linux / macOS
- Микрофон для голосового управления
